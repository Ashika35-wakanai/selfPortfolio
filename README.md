# selfPortfolio
 
My personal portfolio website, built to show who I am, what I have learned, and the projects I have worked on. It is a blank screen with a slime mascot named Shizuka. Click her to open the menu, and each section opens as a draggable window.

## Sections
 
| # | Section | What it shows |
|---|---------|---------------|
| 1 | Home | Name, tagline and a short welcome |
| 2 | About Me | A short introduction and education |
| 3 | Projects | Cafe Rencontre, Purpose and Face Detection |
| 4 | Skills | Tools and languages, shown with logos |
| 5 | Achievements | Certificates in a carousel |
| 6 | Contact | Email, GitHub and LinkedIn |
 
## Features
 
- A slime mascot that opens the menu
- Draggable windows that work with mouse and touch
- Click any project screenshot or certificate to view it larger
- Certificate carousel with arrows and swipe
- Skills grouped by category
- Responsive layout for phones, tablets and desktops
## Built with
 
- HTML5
- CSS3
- JavaScript
- Devicon (skill logos)
- Vercel (hosting)
